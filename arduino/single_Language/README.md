# Arduino single-file versions / Arduino als Einzeldateien

Generated by `tools/bundle_firmware.py` from `arduino/Wordclock` (do not edit here). One sketch folder per language
(`XX` = language code): `Wordclock_XX/Wordclock_XX.ino` (settings of `config.h` inserted, language fixed) and
`Wordclock_XX/wordclock_bundle.h` (all C++ code).

**EN:** copy the folder `Wordclock_XX` of your language into the Arduino sketchbook and open `Wordclock_XX.ino` in
the Arduino IDE 2.x (ESP32 board package by Espressif 2.0.x or 3.x; with 2.0.x also the library "Adafruit
NeoPixel"). Check the settings in the `config.h` part at the top of the `.ino` (`LED_PIN`, current limit, wiring),
choose the board (e.g. "ESP32 Dev Module" / "ESP32C6 Dev Module", partition scheme "Default 4MB with spiffs") and
upload via USB. Folder and `.ino` must keep the same name. First start: hotspot, http://192.168.4.1, enter Wi-Fi.

**DE:** den Ordner `Wordclock_XX` deiner Sprache in den Arduino-Sketchbook-Ordner kopieren und `Wordclock_XX.ino` in
der Arduino IDE 2.x öffnen (ESP32-Boardpaket von Espressif 2.0.x oder 3.x; bei 2.0.x zusätzlich Bibliothek
"Adafruit NeoPixel"). Einstellungen im `config.h`-Teil oben in der `.ino` prüfen (`LED_PIN`, Strombegrenzung,
Verdrahtung), Board wählen (z. B. "ESP32 Dev Module" / "ESP32C6 Dev Module", Partitionsschema "Default 4MB with
spiffs") und per USB hochladen. Ordner und `.ino` müssen gleich heißen. Erster Start: Hotspot, http://192.168.4.1,
WLAN eintragen.
