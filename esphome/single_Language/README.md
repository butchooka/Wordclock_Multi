# ESPHome single-file versions / ESPHome als Einzeldateien

Generated by `tools/bundle_firmware.py` from `esphome/` (do not edit here). One file pair per language
(`XX` = language code): `wordclock_multi_XX.yaml` (main file, core and language in one file) and
`wordclock_multi_XX.h` (all C++ code).

**EN:** copy **both** files of your language to `/config/esphome/` of Home Assistant (e.g. with the File editor
or Samba add-on); `secrets.yaml` there needs `wifi_ssid`, `wifi_password`, `ap_password`, `api_key`,
`ota_password`. All personal values are at the top of the `.yaml` under `substitutions:` - device name
(`name`, `friendly_name`), data pin (`led_pin`, default GPIO32; ESP32-C6: GPIO2), wiring (`serpentine`, `mirror_x`),
current and the Home Assistant entities for alarm, vent, battery and the two temperatures (just the entity ID).
Then "Install" in the ESPHome dashboard. Several clocks: one copy of the `.yaml` per clock with its own `name`,
the `.h` is shared. The multi-file version in `esphome/` (all languages, switch by one line) is the same firmware.

**DE:** **beide** Dateien deiner Sprache nach `/config/esphome/` von Home Assistant kopieren (z. B. mit dem
File-editor- oder Samba-Add-on); `secrets.yaml` dort braucht `wifi_ssid`, `wifi_password`, `ap_password`,
`api_key`, `ota_password`. Alle persönlichen Werte stehen oben in der `.yaml` unter `substitutions:` -
Gerätename (`name`, `friendly_name`), Datenpin (`led_pin`, Standard GPIO32; ESP32-C6: GPIO2), Verdrahtung
(`serpentine`, `mirror_x`), Strom und die Home-Assistant-Entitäten für Alarm, Lüften, Akku und die beiden
Temperaturen (einfach die Entitäts-ID). Dann im ESPHome-Dashboard "Install". Mehrere Uhren: je Uhr eine Kopie der
`.yaml` mit eigenem `name`, die `.h` teilen sich alle. Die Mehrdatei-Version in `esphome/` (alle Sprachen, Umschalten
über eine Zeile) ist dieselbe Firmware.
