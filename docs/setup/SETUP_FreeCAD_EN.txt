Wordclock_Multi v2.0 - Setup FreeCAD
====================================
Generated by tools/make_info.py - do not edit by hand (source: tools/make_info.py).

1. WHAT GOES WHERE
   Copy Wordclock_Model.FCMacro together with the folder lang/ (all lang_XX.scad) into one folder,
   e.g. the FreeCAD macro folder (Macro > Macros... shows the path) or simply use the folder models/.
   The macro reads the grids from lang/lang_XX.scad next to it (other place: LANG_DIR at the top of the macro).

3. IMPORTANT SETTINGS (top of the macro, comments there)
   MODEL / BUILD_* (which parts), CAP_HEIGHT, FRONT_SKIN, ESP_BOARD, FONT_FILE (None = font dialog; languages with their own
   script like JP/CN/KR automatically get a matching installed font, FONT_AUTO / LANG_FONTS),
   FILLER = how the filler cells ("x" in the grid) are printed: "auto" (default: the language's choice
   from lang_XX.scad, e.g. dot for CN/JP/KR, else X), "X", "dot" (dot like the temperature dots,
   size FILLER_DOT) or any character such as "-", "+", "O".
   Filler cells stay open (light chamber), so effects run over the whole face.

4. RUN AND EXPORT
   Macro > Macros... > Wordclock_Model.FCMacro > Execute. With EXPORT = "step" (default, "stl" also works) every part is written in
   print orientation into the folder export/ next to the macro. File names: front/letters
   Wordclock_<part>_v2.0_<LANG>_<font>, all other parts Wordclock_<part>_v2.0 (the same for all languages).

5. SPECIAL MODEL PICTUREFRAME
   The PictureFrame (front plate for a deep picture frame) has been moved out of the macro and is currently
   available in OpenSCAD only (Wordclock_Model_PictureFrame.scad, see SETUP_OpenSCAD). A FreeCAD macro of its
   own will follow.
